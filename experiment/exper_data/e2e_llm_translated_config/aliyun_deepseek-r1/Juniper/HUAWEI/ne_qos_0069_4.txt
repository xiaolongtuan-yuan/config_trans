sysname CE2

interface GigabitEthernet2/0/0
 undo shutdown
 ip address 10.12.1.1 255.255.255.0

ospf 1
 area 0.0.0.0
  network 10.12.1.0 0.0.0.255
##
The configuration establishes:
1. Device hostname equivalent
2. Interface IP address with enabled status (Juniper interfaces default to up)
3. OSPF process 1 with interface network in area 0 (HUAWEI uses dotted notation for OSPF areas)
