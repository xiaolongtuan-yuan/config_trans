The translation maintains equivalent functionality by:
1. Converting Juniper's host-name to Cisco's hostname
2. Adapting interface naming convention (ge-0/0/4 → GigabitEthernet0/0/4)
3. Preserving IPv4 address configuration (unit family inet → direct interface IP)
4. Keeping the interface administratively disabled (disable → shutdown)
