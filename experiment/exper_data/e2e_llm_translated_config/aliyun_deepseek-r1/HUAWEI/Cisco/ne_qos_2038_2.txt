hostname DeviceC
!
interface GigabitEthernet1/0/0
 no shutdown
 ip address 10.20.1.1 255.255.255.0
!
router bgp 100
 neighbor 10.20.1.2 remote-as 100
 !
 address-family ipv4
  no synchronization
  redistribute connected
  neighbor 10.20.1.2 activate
!
router ospf 1
 network 10.20.1.0 0.0.0.255 area 0
##
The translation maintains equivalent functionality with:
1. Interface configuration with same IP parameters
2. BGP peering with same AS numbers
3. Direct route redistribution in BGP
4. OSPF network advertisement in area 0
5. BGP synchronization disabled
6. Neighbor activation in IPv4 address family

Key differences in syntax:
- Cisco uses 'address-family' structure instead of 'ipv4-family'
- OSPF area 0 is represented as single 0 instead of 0.0.0.0
- 'redistribute connected' replaces 'import-route direct'
- Wildcard masks are used in OSPF network statements for both platforms
