##

Explanation:
1. **sysname** translates directly to **hostname**
2. **vlan batch** becomes standard **vlan** declaration
3. **Eth-Trunk** is converted to Cisco's **Port-channel**
4. Physical interface config:
   - **undo shutdown** becomes **no shutdown**
   - **eth-trunk** membership translates to **channel-group** with static mode (default LAG behavior in Huawei). For LACP, use "mode active" instead.
5. Implicit interface enablement (Cisco interfaces are admin-up by default, but explicit "no shutdown" is included for parity)
