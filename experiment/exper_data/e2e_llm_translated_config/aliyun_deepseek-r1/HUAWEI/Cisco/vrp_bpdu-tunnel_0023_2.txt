##
The translation maintains equivalent functionality by:
1. Setting device name with "hostname"
2. Enabling spanning-tree with Cisco's PVST mode (Huawei's default is MSTP)
3. Keeping the interface enabled with "no shutdown"
4. Switching port to L2 mode with "switchport" (equivalent to Huawei's portswitch)
