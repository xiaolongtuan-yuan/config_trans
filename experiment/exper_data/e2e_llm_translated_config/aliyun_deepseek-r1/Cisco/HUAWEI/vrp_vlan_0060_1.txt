sysname CE2

vlan batch 5

interface GigabitEthernet0/0/1
 undo shutdown
 port link-type access
 port default vlan 5

interface GigabitEthernet0/0/2
 undo shutdown
 port link-type access
 port default vlan 5

interface GigabitEthernet0/0/3
 undo shutdown
 port link-type trunk
 port trunk allow-pass vlan 5
##
- The hostname is translated to sysname command in HUAWEI
- VLAN creation uses "vlan batch" instead of separate "vlan" command
- "switchport mode access" becomes "port link-type access"
- "switchport access vlan" becomes "port default vlan"
- "switchport mode trunk" becomes "port link-type trunk"
- "switchport trunk allowed vlan" becomes "port trunk allow-pass vlan"
- Interface naming follows HUAWEI's format (GigabitEthernet0/0/x)
- "no shutdown" is translated to "undo shutdown"
- Maintained equivalent functionality for access ports and trunk port configuration
