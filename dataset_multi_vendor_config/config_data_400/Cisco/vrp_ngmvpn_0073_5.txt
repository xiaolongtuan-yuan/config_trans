 no shutdown
 ip address 10.1.6.1 255.255.255.0
 ip pim sparse-mode
 ip igmp join-group 224.0.0.0
 ip igmp version 2

 no shutdown

 !

  no synchronization
  redistribute connected
  neighbor 192.168.2.2 activate
