 rd 100:1

 no shutdown
 ip address 10.1.1.1 255.255.255.0
 mpls ip
 mpls traffic-eng tunnels
 mpls rsvp-te

 no shutdown

 mpls ip

 !

  neighbor 3.3.3.9 activate
  neighbor 3.3.3.9 next-hop-self

  neighbor 3.3.3.9 activate
  neighbor 3.3.3.9 next-hop-self

  network 1.1.1.9 0.0.0.0
  network 10.2.1.0 0.0.0.255
