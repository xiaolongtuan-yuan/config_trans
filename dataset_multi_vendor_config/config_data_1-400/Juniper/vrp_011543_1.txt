set protocols cfm domain md3 association ma3 vlan-id 2
set protocols cfm domain md3 association ma3 mep 4 interface ge-1/0/1 direction down
set protocols cfm domain md3 association ma3 mep 4 ccm enable
set protocols cfm domain md3 association ma3 remote-mep 3
set protocols cfm domain md3 association ma3 remote-mep 3 ccm-receive enable
set protocols cfm domain md3 association ma3 mep 4 delay-measure receive test-id 1
set protocols cfm domain md3 association ma3 mep 4 delay-measure send test-id 2 remote-mep 3 interval 1000

set interfaces ge-1/0/1 unit 0 family ethernet-switching port-mode trunk
set interfaces ge-1/0/1 unit 0 family ethernet-switching vlan members vlan2
set interfaces ge-1/0/1 disable
