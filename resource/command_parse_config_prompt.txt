The router configuration command is parsed into JSON according to the following JSON format.
- **template** : A common format for configuration commands
- **command** : Concrete command examples
- **explanation** : The explanation of the command template
- **parameters** : A list of parameters, each containing:
  - **name** : The parameter name
  - **type** : The type of the parameter
  - **explanation** : explanation of the parameters

Example:
# command:
interface GigabitEthernet1/0/0

# response：
{
"template": "interface [parameter1]",
"command": "interface GigabitEthernet1/0/0",
"explanation": "Configure interface",
"parameters": [
  {
    "name": "interface name",
    "type": "string",
    "explanation": "interface name"
  }
  ],
}

### Task:
Please convert this command to JSON and output it directly in JSON format:
{command}
