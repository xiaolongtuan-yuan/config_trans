Please parse the Huawei configuration to JSON according to the following format. Each configuration command acts as a node whose key is the configuration command itself and whose value is the parsed JSON structure. The following information is extracted during parsing:
- 'template' : Generic format for config commands
- 'command' : Concrete command examples
- 'explanation' : The explanation of the command
- 'parameters' : a list of parameters, each containing:
  - 'name' : Parameter name
  - 'type' : The type of the parameter
  - 'explanation' : explanation of the parameter

If the command contains a child configuration, it is nested as its child node and parsed in the same way.
### Example:
#### Config command
sysname PE2

interface GigabitEthernet1/0/0
    undo shutdown
    ip address 192.168.0.1 255.255.255.0

#### for JSON:
{
  "sysname PE2": {
    "template": "sysname [parameter1]",
    "command": "sysname PE2",
    "explanation": "Set the device host name to 'PE2'",
    "parameters": [
      {
        "name": "host name",
        "type": "string",
        "explanation": "hostname"
      }
    ]
  },
  "interface GigabitEthernet1/0/0": {
    "template": "interface [parameter1]",
    "command": "interface GigabitEthernet1/0/0",
    "explanation": "...'",
    "parameters": [
      {
        "name": "interface name",
        "type": "string",
        "explanation": "Interface name"
      }
    ],
    "undo shutdown": {
      "template": "undo shutdown",
      "command": "undo shutdown",
      "explanation": "Enable the interface (the interface is disabled by default)",
      "parameters": []
    },
    "ip address 192.168.0.1 255.255.255.0": {
      "template": "ip address [parameter1] [parameter2]",
      "command": "ip address 192.168.0.1 255.255.255.0",
      "explanation": "The IPv4 address of the configuration interface is 192.168.0.1, and the subnet mask is 255.255.255.0",
      "parameters": [
        {
          "name": "ip address",
          "type": "IPv4",
          "explanation": "IPv4 address"
        },
        {
          "name": "sub musk",
          "type": "IPv4",
          "explanation": "subnet mask"
        }
      ]
    }
  }
}
