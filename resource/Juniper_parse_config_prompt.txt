请按照以下格式将Juniper配置解析为 JSON，每条配置命令作为一个节点，节点的键为配置命令本身，值为解析后的 JSON 结构。解析时需提取以下信息：
- **template**：配置命令的通用格式
- **command**：具体的命令示例
- **explanation**：命令的解释
- **parameters**：参数列表，每个参数需包含：
  - **name**：参数名
  - **type**：参数类型
  - **explanation**：参数解释

若命令包含子配置，则作为其子节点嵌套，解析方式相同。

### 示例：
#### 配置命令：
set system host-name Hub

set interfaces ge-1/0/0 unit 0 family inet address 10.1.1.10/24
set interfaces lo0 unit 0 family inet address 192.168.0.1/32
